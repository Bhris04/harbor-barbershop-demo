# Harbor Barbershop Demo

[View the live website](https://bhris04.github.io/harbor-barbershop-demo/)

## Project overview

A fictional small-business website demo built to make basic business information easy to find.

## Features

- Service and sample-price section
- Hours section
- Navigation links to page sections
- Expandable FAQ answers
- Layout that adjusts for smaller screens

## Built with

HTML and CSS

## Note

Harbor Barbershop and all business details on this site are fictional. This demo does not accept real appointments.
